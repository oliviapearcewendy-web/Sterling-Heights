STERLING HEIGHTS WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the sterling-heights folder in Visual Studio Code.
3. Open index.html with the Live Server extension.

PAGES
- index.html: Home
- pages/finished.html: Finished projects
- pages/ongoing.html: Ongoing projects
- pages/details.html: Project details
- pages/about.html: About Sterling Heights
- pages/contact.html: Contact form
- pages/signup.html: Create an account
- pages/login.html: Log in
- pages/profile.html: User profile

ACCOUNT AND FORM LIMITATIONS
This is a frontend-only website. Account information is stored in the current browser using localStorage, and the password digest is created in the browser. This does not replace secure server-side authentication. Do not use it to protect real customer accounts or sensitive information. The contact form currently displays an on-page confirmation and does not send messages to a server.

Project locations are set in the United States (Austin, Denver, Charlotte, Scottsdale, and Raleigh). Replace project descriptions, locations, progress figures, and statistics with verified company information before publishing. Property images and fonts load from external services and require an internet connection.
